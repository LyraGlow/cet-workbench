# 四六级备考工作台

面向大学生四六级备考的纯前端学习平台：真实英语时事 + 真题篇幅精读 + 听力听写 + 完整词库 + 语法专项 + 作文素材库。

## 功能一览

| 模块 | 说明 |
|---|---|
| 📰 英语时事 | 每天自动抓取 CGTN 英文新闻（10~15 条，已验证链接可访问），点击可看原文 |
| 📖 阅读理解 | 四级 300~350 词 / 六级 400~450 词精读文章，含全文译文、重点词汇、3 道理解题自动判分 |
| 🎧 听力听写 | VOA 慢速英语风格短材料 + 校园情景对话，逐句听写、逐词判分、可调语速 |
| 🃏 背单词 | 四级 4540 词 / 六级 5716 词（含四级基础词），卡片记忆 + 艾宾浩斯复习（1/2/4/7/15 天） |
| 📐 语法语态 | 12 个高频语法知识点（时态、被动、虚拟、非谓语、各类从句、情态动词、主谓一致、倒装、比较结构、固定搭配）+ 专项练习与解析 |
| ✍️ 作文素材 | 摘抄好句好段，按开头句/过渡句/结尾句等分类，一键复制 |
| ⭐ 生词本 | 点击阅读/听力原文中任意单词即可查释义、加星收藏，并加入背单词词库 |

**分级切换**：页面右上角「四级 / 六级」切换，文章、听力、词库、倒计时联动。

## 快速开始

- **本地使用**：双击 `index.html`
- **线上使用**：见 `GitHub部署步骤.md`（免备案，可分享给他人，新闻每天自动更新）

## 目录结构

```
index.html                      页面与交互逻辑
content.js                      每日内容包（新闻/文章/听力/对话）
grammar.js                      语法知识点库
words.js                        四六级词库数据
scripts/update_news.py          每日新闻抓取脚本（GitHub Actions 调用）
.github/workflows/daily-news.yml 定时任务配置（每天北京时间 6:30）
使用说明.md                     使用、分享与手动更新方式
GitHub部署步骤.md               上线到公网的完整步骤
```

## 数据与隐私

背单词进度、生词本、作文素材、设置均保存在**本机浏览器 localStorage**，不上传任何服务器，不同人互不影响。

## 说明

所有精读文章、听力材料、语法讲解与练习均为**原创教学改写**，不复制受版权保护的原文；新闻仅展示标题与真实原文链接。
