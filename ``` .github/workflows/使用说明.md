# 四六级备考工作台 · 使用与分发说明

## 一、这是什么

一个**双击就能用的本地网页**，包含四大学习模块：

| 模块 | 内容 |
|---|---|
| 📰 英语时事 | 真实抓取的 CGTN 英文新闻（可点标题看原文），每天更新 |
| 📖 阅读理解 | 四六级真题篇幅的精读文章（四级 300~350 词 / 六级 400~450 词）+ 3 道理解题 + 全文译文 |
| 🎧 听力听写 | VOA 慢速英语风格短材料 + 校园情景对话，逐句听写、自动判分 |
| 🃏 背单词 | 四级 4540 词 / 六级 5716 词（含四级基础词），卡片记忆 + 艾宾浩斯复习 |
| 📐 语法语态 | 12 个高频语法知识点讲解 + 专项练习（带解析） |
| ✍️ 作文素材 | 摘抄好句好段，按类型分类，一键复制 |
| ⭐ 生词本 | 阅读/听力中点任意单词即可查释义、一键加星收藏 |

> **想分享给别人、让它每天自动更新？** 见 `GitHub部署步骤.md`——里面配了「GitHub 英文按钮中文对照表」，每一步都写清点哪个按钮、按钮什么意思，照做即可（免备案、免费、不需要本机开机）。

## 二、怎么打开

双击 **`index.html`** → 自动在浏览器打开。

更省事的做法：
- **桌面图标**：把 `index.html` 拖到桌面，或创建一个指向它的快捷方式；
- **开始菜单**：按 `Win` 键输入"四六级"即可搜索启动（需先放快捷方式到开始菜单）；
- **开机即开**：在浏览器「设置 → 启动时 → 打开以下页面」里加入本页的 `file://` 地址；
- 打开后可加为书签（`Ctrl+D`）。

> 学习数据（背单词进度、生词本）存在**本机浏览器**里，换浏览器或清理浏览器数据会丢失。
> 文章、单词、听力**完全离线可用**；只有点新闻标题看原文需要联网。

## 三、内容是怎么更新的（重要）

内容全部存放在 **`content.js`** 里，页面只负责显示。更新有两种方式：

### 方式 A：本机自动更新（推荐，需要 WorkBuddy 在运行）
在本机 WorkBuddy 里创建一个**每日自动化任务**，每天固定时间执行下面的提示词。
⚠️ 前提：执行那一刻 WorkBuddy 正在运行（电脑开机、程序没关）。否则当天跳过，不保证补跑。

### 方式 B：一句话手动更新（最可靠）
打开 WorkBuddy，把下面这段发给它即可（几秒钟开始，约 1 分钟完成）：

```
更新四六级工作台今天的内容：抓取 CGTN 的 china / world / business / sports / culture / travel 六个频道 RSS，
只保留 curl 验证返回 200 的真实链接（禁止手写拼 URL），选 10~15 条、以体育/文化/旅游/商业等轻松题材为主，
政治与暴力灾难类合计不超过三分之一；然后按 content.js 现有格式：
- 四级、六级各新增 1 篇精读文章（四级 300~350 词、六级 400~450 词，含中文译文、重点词汇、3 道理解题）
- 四级、六级各新增 1 段 VOA 慢速英语风格听力（120~180 词，含译文）
- 新增 1 段校园情景对话
中文文本内只用中文引号“ ”，写完跑 node --check 校验语法，最后把 updated 改成今天日期。
只改 content.js，不要动 index.html 和 words.js。
```

## 四、分享给别人的正确方式

### 情况 1：对方只想用，不需要每天更新
把 **`cet-workbench` 整个文件夹**（3 个文件）复制给对方，让对方双击 `index.html` 即可。
→ 内容会停留在你复制的那一刻，**不会自动更新**（网页本身无法自己抓新闻：浏览器跨域限制 + 国内公共代理不可靠）。
→ 页面上会显示"内容包更新于 X 月 X 日"，过期时自动弹出提醒条。

### 情况 2：对方也要每天自动更新
对方需要在自己电脑的 WorkBuddy 里：
1. 把这个文件夹放到自己电脑的某个目录；
2. 新建一个**每日定时任务**（例如 6:30）；
3. 把上面「方式 B」那段提示词粘进去，**把里面的 `content.js` 路径改成他自己电脑上的路径**。

这样对方的 WorkBuddy 会每天更新他自己那份内容包。

### 情况 3：想一次分享给很多人、人人打开就是最新
本地文件做不到，需要**部署到公网 + 一个后端定时任务**：把网页放到服务器/托管平台，
由服务器每天定时抓新闻、生成文章，所有人打开同一个网址看到最新内容。
这一版需要：托管平台 + 域名 + （国内正式运营还需 ICP 备案）。需要时再单独做。

## 六、常见问题

**Q：打开后新闻一片空白？** 页面上显示的是内容包里的新闻。若内容包为空或日期很旧，按「方式 B」让助手更新一次。

**Q：点新闻标题报"页面未找到"？** 说明内容包里的旧链接失效了，更新一次内容即可（新链接都会预先验证可访问）。

**Q：背单词进度会不会丢？** 存在本机浏览器里，同一台电脑同一个浏览器不会丢；换设备或清理浏览数据会丢。

**Q：听力没有声音？** 使用浏览器语音合成朗读（建议 Edge / Chrome）。请检查系统音量和浏览器是否被静音。
